# QuantFlow V1.3.0

补齐回测引擎的**期货（Future）资产能力**，使平台覆盖「股票 / 基金 / 期货」三类资产的策略回测；
同时交付「示例工作流模板库」前端入口与工程化收尾（文档与 OpenAPI 可及性），版本号 1.3.0。

## 里程碑交付

### F1 · 期货账户与保证金模型（`FuturesAccount`）
- 新模块 `app/backtest/futures.py`：多空净仓模型（`direction: long/short`），`order_future` 买平空开多、卖平多开空，自动净额处理
- 保证金占用 `margin_occupied = |contracts| * multiplier * price * margin_rate`；权益 `equity = cash + floating_pnl`；可用 `available = equity - margin`
- 盯市结算 `settle`：浮盈浮亏计入权益；若 `equity <= maintenance_margin` 触发 `close_all`（强平，`forced_liquidations += 1`）
- 非整手委托 → `OrderRejected`；无行情价 → 返回 `None`（跳过）

### F2 · 引擎集成（多账户净值聚合）
- `BacktestEngine` 识别 `future` 市场标的，独立维护 `futures_account`
- `_aggregate_equity` 对股票/基金/期货多账户按「初始资金不重复计」口径聚合（n 个账户减 (n-1) 份 `initial_cash`）
- `BacktestContext` 新增 `order_future(symbol, contracts, side, limit_price)` 与 `close_future_all(symbol=None)`；对期货标的 `order` 返回 `None`（必须走 `order_future`）

### F3 · 期货策略与接口
- `FuturesMaCrossStrategy`（`futures_ma_cross`）：金叉做多、死叉做空（多空净仓切换），默认 fast=5/slow=20
- `backtest.run` 节点新增 `futures_ma_cross` 策略、`future` 资产类型、`contracts`（手数）、`multiplier`（合约乘数，默认 10）
- `POST /api/backtest/run` 与 `POST /api/backtest/portfolio` 腿均支持 `asset_types`/`multipliers` 期货语义
- 成本模型 `CostRates` 扩展：期货手续费（元/手）、保证金率、维持保证金率

### F4 · 示例工作流模板库
- 后端内置模板扩至 3 个：`ma_cross`（股票均线）、`momentum`（股票动量）、`futures_ma_cross`（期货均线多空），经 `GET /api/workflows/templates` 暴露
- 前端新增「模板库」页（顶栏入口），选中模板一键载入编辑器画布
- `TEST.FUTURE` fixture 由 20 日扩至 55 日（下跌→上涨→下跌），保证默认 `futures_ma_cross` 可稳定触发金叉+死叉

### F5 · 工程化收尾
- `main.py` 将 Swagger/ReDoc/OpenAPI 路径收口到 `/api` 前缀（`/api/docs`、`/api/redoc`、`/api/openapi.json`），经反向代理（prod/docker）直接可达
- README 刷新：版本 1.3.0、能力表补期货/组合/调度/模板库、测试数 344、新增 API 文档章节
- 本发布说明与 `docs/` 既有 V1.1.0 格式对齐
