### 1.2 回测手工对照基准集复核

以下关键基准用例全部通过（`tests/test_backtest.py` / `tests/test_fund.py`）：

**基金手工对照（数值逐项核对）**
- 净值 1.0→1.1→1.2，首日申购 1 万、末日全赎：
  - d1 总资产 = 999_985（申购费 15 摊入成本，份额 9985）
  - d2 总资产 = 1_000_983.5（份额按 1.1 估值）
  - d3 总资产 = 1_001_922.09（1.2 赎回，赎回费 0.5%）
  - 赎回 pnl = 9985×1.2×(1-0.005) - 10000
  - total_return = 1001922.09/1000000 - 1；turnover = (10000+9985×1.2)/1000000
- 基金忽略涨跌停、volume=0 仍可交易、混合股票+基金组合净值、报告含基金

**股票手工对照**
- 佣金最低 5 元、印花税仅卖出 0.1%、过户费双边、滑点方向
- T+1 当日买入禁卖、涨停禁买/跌停禁卖、停牌跳过
- 部分卖出均价成本不变、已实现盈亏、总收益/回撤/胜率/换手
- 引擎级：涨停买入被拒、跌停卖出被拒、停牌标跳过

全量 210 用例通过，覆盖率 91%，回测手工对照基准集数值完全吻合（误差 < 1e-6）。**M5-1 ✅**

## 3. 安全测试（M5-3）

工具：`backend/scripts/security_test.py`（黑盒，25 项）+ `backend/tests/test_security.py`（7 个 CI 用例，加入回归套件，全量现为 **217 passed**）。

| 类别 | 用例 | 结果 |
|---|---|---|
| 未授权访问 | 匿名访问 /api/projects、/api/logs、/api/monitoring/overview、/metrics → 401 | ✅ 4/4 |
| JWT 安全 | 篡改 payload（改 role/username）→ 401；错误密钥伪造 → 401；无签名 → 401；过期 → 401 | ✅ 4/4 |
| RBAC 越权 | B(viewer) 删项目 → 403；C(非成员) 删项目 → 403；C 读他人工作流 → 403；C 列表项目工作流隔离（空集） | ✅ 5/5 |
| SQL 注入 | 登录名 `' OR '1'='1` 等 3 式 → 401/422；项目名注入 → 非 500（参数化查询生效） | ✅ 4/4 |
| 日志注入 | 项目名含换行/花括号 → 非 500（JSON 结构化日志天然防注入） | ✅ 1/1 |
| 弱口令/校验 | 短密码 422；非法用户名 422 | ✅ 2/2 |

**结论**：认证/授权链路无越权漏洞，JWT 篡改与伪造均被拒，SQL 参数化查询生效，日志结构化无注入面。**M5-3 ✅**
