# QuantFlow 用户操作手册

> 适用版本：V1.2 ｜ 更新日期：2026-08-13

QuantFlow 是量化交易 + 机器学习的可视化工作流平台：通过画布拖拽节点、连线构建策略流水线，运行后可实时查看每个节点的中间结果，并一键回测验证策略。

## 一、账号与项目

### 1.1 注册与登录

- 打开平台首页，点击右上角「登录」→ 切换「注册」Tab。
- 用户名 `A-Za-z0-9_`（3~32 位），密码 6~128 位。
- **首个注册用户自动成为管理员（admin）**，可查看全部用户/项目、访问监控指标；后续用户为普通 user。
- 角色：`admin`（平台管理员）/ `user`（普通用户）/ `viewer`（项目只读成员）。

### 1.2 项目管理

- 顶栏项目下拉框可选择当前项目；「＋」创建新项目，创建者自动成为 owner。
- 项目成员角色：
  - `owner`：删除项目、管理成员、编辑（不可被移除）
  - `admin`：管理成员、编辑
  - `member`：编辑
  - `viewer`：只读
- 成员管理在项目菜单中操作（owner/admin 可添加/移除成员）。
- **工作流按项目隔离**：只看到自己创建的、或所在项目下的工作流。

## 二、可视化工作流编排

### 2.1 节点面板

左侧节点面板按分组展示节点库（数据 / 处理 / 特征 / 因子 / ML / 回测 / 数学 / 表格），支持搜索过滤与分组折叠。拖拽或点击将节点加入画布。

### 2.2 画布连线

- 从节点输出端口拖到另一节点输入端口建立数据流。
- 连线有类型检查（number/string/boolean/array/table，`any` 通配），类型不匹配会被拒绝并提示。
- 自连、重复连线会被拒绝；`Ctrl+Z` / `Ctrl+Shift+Z` 撤销重做。

### 2.3 属性面板

选中节点后，右侧属性面板按节点 schema 自动生成表单（数字/文本/布尔/下拉），并显示端口类型徽章。参数有默认值，修改即时生效。

### 2.4 常用节点速查

| 分组 | 节点 | 用途 |
|---|---|---|
| 数据 | `data.quotes` | 拉取股票/基金行情到 DataTable |
| 数据 | `data.financial` | 财务数据 |
| 特征 | `indicator.ma / ema / macd / rsi / kdj / boll` | 技术指标 |
| 因子 | `factor.expression` | pandas 表达式引擎（如 `close > ma5`） |
| 因子 | `factor.ic` | IC / ICIR 计算 |
| ML | `ml.train / ml.predict` | XGBoost / LightGBM / RandomForest 训练与预测（模型经端口传递，可落盘） |
| 回测 | `backtest.run` | 接入回测引擎运行策略（buy_hold / ma_cross / fund_dingtou） |
| 回测 | `backtest.performance` | 绩效指标（收益/回撤/夏普/胜率/换手） |
| 回测 | `backtest.export_json / export_csv` | 结果导出 |

## 三、运行与可视化

1. 点击「保存」将工作流入库（可重命名/删除/JSON 导出导入）。
2. 点击「运行」异步执行 DAG：
   - 节点按拓扑序执行，独立分支并发；
   - 运行中节点实时变色（运行中/成功/失败/阻塞），失败节点红框标注并向下游传播 BLOCKED；
   - 每个节点输出可在属性面板「输出预览」查看。
3. 失败排查：看红色节点 → 属性面板错误信息 → 调整参数/连线后重跑。

## 四、K 线图表页

图表页用 lightweight-charts 展示行情 K 线 + 成交量副图，数据来自 `/api/market/bars`。

## 五、监控页（管理员）

- **概览卡片**：服务运行时长、运行实例统计（成功/失败/排队）、注册节点数、WebSocket 连接数。
- **日志查询**：按级别（DEBUG/INFO/WARNING/ERROR）与关键词过滤，每条日志带 `request_id` / `user_id`，暗色等宽展示。
- **指标**：`/api/monitoring/metrics` 输出 Prometheus 文本格式（admin 专属）。
- 非 admin 用户仅可见系统日志与自己的操作日志。

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 行情节点取不到数据 | 后端需 `QF_MARKET_PROVIDER=fixture`（离线内置数据）或配置 tushare token |
| 运行全部 BLOCKED | 检查数据源节点是否成功，上游失败会阻塞下游 |
| 回测 422 | 检查标的在所选区间是否有行情、策略名是否正确 |
| 忘记密码 | 联系管理员（V1.0 无自助找回） |
