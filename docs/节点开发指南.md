# QuantFlow 节点开发指南

> 适用版本：V1.0 ｜ 更新日期：2026-08-12

本文面向需要扩展 QuantFlow 节点库的开发者。后端节点是纯 Python 类 + 装饰器注册，无需改前端即可出现在画布面板并自动生成属性表单。

## 一、框架核心

| 符号 | 位置 | 作用 |
|---|---|---|
| `BaseWorkNode` | `app/core/node.py` | 节点抽象基类，实现 `execute(ctx, inputs)` |
| `work_node(...)` | `app/core/node.py` | 装饰器：注册节点类型 + 元数据（spec） |
| `PortSpec(name, dtype)` | `app/core/node.py` | 端口定义，dtype ∈ number/string/boolean/array/table/any |
| `ParamSpec(name, dtype, ...)` | `app/core/node.py` | 参数定义，前端据此自动渲染表单 |
| `DataTable` | `app/core/data.py` | 表格数据类型（列名 + 行数据，JSON 可序列化） |
| `REGISTRY` | `app/core/registry.py` | 节点注册表，`GET /api/nodes` 输出全部 spec |

类型系统（DAG 连线校验用）：

```
number | string | boolean | array | table | any（通配）
```

## 二、最小节点示例

```python
# 文件：backend/app/nodes/your_module.py
from typing import Any
from ..core.node import BaseWorkNode, ParamSpec, PortSpec, work_node


@work_node(
    "example.double",            # 全局唯一 node_type（三段命名：分组.名称）
    label="翻倍",                # 面板显示名
    category="数学",              # 分组（决定面板分组）
    description="输入数值 ×2",
    inputs=[PortSpec("value", "number")],
    outputs=[PortSpec("result", "number")],
    params=[ParamSpec("factor", "number", default=2.0, label="倍数")],
)
class DoubleNode(BaseWorkNode):
    def execute(self, ctx, inputs):
        value = inputs["value"]           # 上游端口数据
        factor = self.params["factor"]    # 节点参数（已按 schema 校验/默认值填充）
        return {"result": value * factor}
```

### 注册节点

后端启动时需导入模块触发装饰器注册。在 `backend/app/nodes/__init__.py` 中追加：

```python
from . import your_module  # 触发 @work_node 注册
```

> `app/main.py` 导入 `app.nodes`，因此只要模块被 `__init__.py` 引入即可。

## 三、节点规范（spec）

注册后 `GET /api/nodes` 会返回该节点的规范，前端节点面板/属性面板/连线校验均以 spec 为唯一来源：

```json
{
  "type": "example.double",
  "label": "翻倍",
  "category": "数学",
  "description": "输入数值 ×2",
  "inputs": [{"name": "value", "type": "number"}],
  "outputs": [{"name": "result", "type": "number"}],
  "params": [{"name": "factor", "type": "number", "default": 2.0, "label": "倍数", "required": false}]
}
```

### ParamSpec 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | str | 参数名（self.params 键） |
| `type` | str | number/string/boolean/select |
| `default` | Any | 默认值 |
| `label` | str | 表单标签 |
| `required` | bool | 是否必填 |
| `options` | list | type=select 时选项列表 |

## 四、execute 上下文

`execute(self, ctx, inputs)`：

- `inputs`：`dict[name → 上游输出值]`，key 为 input 端口名。
- `self.params`：`dict[name → 参数值]`，已合并默认值并完成基本类型转换。
- `ctx`：运行上下文（`ctx.logger` 可打印运行日志）。

**返回值**：`dict[name → 值]`，key 必须与 outputs 端口名一一对应。

## 五、表格数据约定

`DataTable`（`.columns: list[str]` + `.rows: list[dict]`）：

```python
from ..core.data import DataTable

tbl = DataTable(columns=["date", "close"], rows=[{"date": "2024-01-01", "close": 10.0}])
```

- 序列化时 NaN/inf 会转为 `None`（`nodes/_utils.py` 的 `table_to_dict`），保证 JSON 兼容。
- 数据表节点返回 `{"table": tbl}` 或 `{"table": table_to_dict(tbl)}` 均可。

## 七、规范与测试

1. **node_type 唯一**：用「分组.名称」命名，避免与内置节点冲突。
2. **类型诚实**：输出端口 dtype 与实际返回类型一致，否则下游类型校验会拒绝连线。
3. **纯函数**：execute 不要持有跨运行状态；大对象（模型等）经端口传递或落盘 `backend/data/`。
4. **加测试**：仿照 `tests/test_nodes_m3.py`（45 用例，指标手算精确值、ML roundtrip、E2E 工作流），至少覆盖：正常输入、边界输入、错误输入抛 `NodeExecutionError`/`ValueError`。
5. **校验**：`pytest tests/ -q` 全绿后再提交。

## 八、工作流执行流程（背景知识）

```
POST /api/workflows → 校验 DAG（拓扑/环/端口/单输入源）
POST /api/runs     → 异步执行：拓扑序 + 并发调度 + 失败传播
WS /api/ws/runs/{run_id} → snapshot + node_running/succeeded/failed/blocked + run_succeeded/failed
```
